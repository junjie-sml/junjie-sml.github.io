Software & Tools

Open-source computational frameworks for gene network inference and spatial omics analysis. * Equal contribution.

  • SpiderNet

    Uncovers cell–cell interaction modules in tissues from spatial transcriptomics.

    [Tang, J., Liang, S., Ma, J., not preprint now]

  • PLNet

    Network inference for Poisson log-normal model based on the Dtrace method.

    [Xiao, F.*, Tang, J.*, Fang, H., Xi, R., Advances in Neural Information Processing Systems (NeurIPS)]

  • SCVMPLN

    Variational inference for Mixture Poisson Log-Normal graphical model in single-cell gene regulatory network analysis with mixed cell populations.

    [Tang, J., Wang, C., Xiao, F., Xi, R., Quantitative Biology]

  • SpaHDmap

    Interpretable high-resolution dimension reduction of spatial transcriptomics data.

    [Tang, J.*, Chen, Z.*, Qian, K.*, et al., bioRxiv]
