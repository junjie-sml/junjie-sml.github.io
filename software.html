Software & Tools

Open-source computational frameworks and analytical tools developed for understanding spatial omics, multiscale interactions, and social neuroscience.

SpiderNet

SpiderNet is an interpretable deep learning framework that infers directional cell–cell meta-interactions from spatial transcriptomics data. It integrates graph neural networks, non-negative factorization, and attention-based mechanisms to reveal multiscale communication structures within tissues.

[GitHub] [Documentation]

SpaHDmap

SpaHDmap performs interpretable high-resolution dimensionality reduction for spatial transcriptomics. It aligns biological activity patterns with spatial context, enabling fine-grained visualization and feature interpretation.

[GitHub] [Preprint]

CellFlowMap

CellFlowMap is a temporal extension of SpiderNet designed to model dynamic cell–cell communication flow and perturbation effects across time points.

[GitHub]

SOAR-X

SOAR-X (Spatial Omics Attention-based Representation with eXplainability) is a self-supervised attention model that decomposes cell interactions into intrinsic, local, and global components, providing biologically interpretable embeddings.

[GitHub]
